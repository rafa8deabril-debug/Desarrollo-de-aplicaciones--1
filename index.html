Desarrollo de Aplicaciones 1

Este curso de Desarrollo de Aplicaciones 1 introduce los fundamentos esenciales de la programación, permitiendo comprender la lógica computacional, estructuras básicas y el desarrollo de soluciones tecnológicas modernas. A lo largo del curso se fortalecerán habilidades analíticas, pensamiento lógico y creatividad digital mediante ejercicios prácticos, desarrollo de programas y proyectos aplicados al mundo real.

HIT

Introducción a HIT

HIT representa el desarrollo tecnológico aplicado a la educación y la innovación digital. En esta sección se presentan recursos, contenidos y herramientas fundamentales que permiten mejorar las capacidades tecnológicas y fortalecer el aprendizaje en programación y desarrollo de software.

Introducción a GitHub

GitHub es una plataforma que permite almacenar proyectos, gestionar versiones de código y compartir desarrollos con otros programadores. En esta sección se visualizarán repositorios, proyectos desarrollados y avances realizados durante el curso.

Semanas del Curso

Semana 1

Introducción a variables y tipos de datos. Se aprende a declarar variables y comprender los diferentes tipos de información utilizados en programación.

Ver Documento

Semana 2

Estudio de estructuras condicionales que permiten tomar decisiones dentro de un programa mediante condiciones lógicas.

Ver Documento

Semana 3

Uso de bucles repetitivos para ejecutar instrucciones múltiples veces según una condición establecida.

Ver Documento

Semana 4

Creación de métodos y funciones para organizar el código y reutilizar instrucciones dentro de un programa.

Ver Documento

Semana 5

Trabajo con arreglos y listas para almacenar grandes cantidades de datos y procesarlos de manera eficiente.

Ver Documento

Semana 6

Manipulación y manejo de datos mediante estructuras organizadas y operaciones sobre conjuntos de información.

Ver Documento

Semana 7

Aplicación de programación modular para dividir el código en partes más pequeñas y reutilizables.

Ver Documento

Semana 8

Desarrollo del proyecto final integrando todos los conocimientos aprendidos durante el curso.
